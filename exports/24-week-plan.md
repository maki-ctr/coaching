# 24-week plan

Generated from `index.html`. Do not edit by hand.

**Week 1**
- Complete the onboarding modules in the Learning Center
- Share the course calendar with the club and family
- Set up filming: a tripod position that covers the whole area

**Week 2**
- Write game model v1: identity and principles for each moment
- Watch one match and note three recurring problems
- Film one full session as a baseline

**Week 3**
- Review the baseline video with the intervention logger
- Share the game model with staff and agree on shared vocabulary
- Draft three KPIs that measure the game model

**Week 4**
- Swap a session video with a course colleague for peer review
- Write a block-one reflection
- Update the game model to v1.1

**Week 5**
- Plan a session for an in-possession principle
- Run it, film it, log the interventions
- Write a five-line reflection

**Week 6**
- Plan a session for an out-of-possession principle
- Coach mostly in flow: one stoppage maximum per practice
- Compare intervention stats with week 3

**Week 7**
- Plan a transition session
- Write progressions and regressions in advance
- Get feedback from a mentor or course educator

**Week 8**
- Map a training week against match day (MD-4 to MD-1)
- Review all four sessions against the assessor's lens
- Add the best two sessions to the portfolio

**Week 9**
- Write a game plan for the next opponent from the game model
- Script the pre-match talk: three messages maximum
- Note what you said at half-time and why

**Week 10**
- Post-match review: track two KPIs
- Train the problem from the match this week
- Game plan #2

**Week 11**
- Rehearse half-time talks with the three-minute timer
- Agree in-game cue words with the captain
- Game plan #3, with a review

**Week 12**
- Game plan #4, with a review
- Review your touchline behaviour on video
- Mid-course reflection: strengths and gaps by competency

**Week 13**
- Choose three players with different profiles for development plans
- Agree targets with each player in a one-to-one
- Set review dates

**Week 14**
- Build individual targets into team sessions
- Film one clip per player on their target
- Note each player's growth and maturation context

**Week 15**
- Mid-point player reviews
- Adjust targets based on the evidence
- Psychosocial check-ins

**Week 16**
- Final player-plan reviews with video
- Add the plans to the portfolio
- Reflection: what changed for each player

**Week 17**
- Write event definitions for your KPIs
- Code one full match
- Compare with a second coder if possible

**Week 18**
- Build a four-clip team video meeting
- Deliver it and note what the players took away
- Link the analysis to the next session

**Week 19**
- Code a second match
- Check trends across matches
- Update any KPI that doesn't reflect the game model

**Week 20**
- Write a one-page analysis summary
- Update to game model v2 from the evidence
- Add the analysis report to the portfolio

**Week 21**
- Portfolio audit: four pieces of evidence per competency
- Mock interview: five prompts out loud, recorded
- Work on the weakest competency first

**Week 22**
- Rehearse the game-model pitch to two minutes
- Plan the final filmed session against the assessor's lens
- Mock interview: five more prompts

**Week 23**
- Review the final session with the logger and rubric
- Final game plan and review
- Tidy the evidence library

**Week 24**
- Final assessments
- Write a full-course reflection
- Plan the 12-month hold period toward the A
